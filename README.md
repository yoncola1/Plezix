# ![Logo](chrome/app/theme/chromium/product_logo_64.png) Plezix

## 🇬🇧 English

**Plezix** is an open-source browser project focused on creating a safer, faster, and more stable web experience for everyone.
Built with performance, security, and modern web technologies in mind, Plezix aims to redefine how users interact with the internet.

### 🚀 Getting Started

To download the source code locally, **do not use `git clone`**.
Because of the project's size and infrastructure, you should follow the official setup guide instead:

👉 `docs/get_the_code.md`

### 📚 Documentation

All main documentation is located in:

* `docs/README.md`

There you can find:

* build instructions,
* architecture overview,
* development guides,
* project structure explanations,
* contributor information.

### 🧩 Project Structure

For historical reasons, the repository contains several top-level directories.
Current development guidelines state that new top-level directories should only be created for standalone products such as:

* Chrome
* Android WebView
* Ash

Even if a product contains multiple executables, its code should remain inside that product’s subdirectories.

## 🧩 Структура проекта

Исторически репозиторий содержит несколько корневых директорий.
Сейчас действует правило:

> новые top-level директории создаются только для отдельных продуктов
> (например: Chrome, Android WebView или Ash).

Даже если продукт содержит несколько исполняемых файлов, весь связанный код должен находиться внутри поддиректорий этого продукта.
